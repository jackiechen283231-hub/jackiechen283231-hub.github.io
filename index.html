kakaer-drive

广州卡卡尔汽车改装设计（Kakaer Automobile）的官方数据工具页面 —— 用于通过 Google Drive 官方接口读写与本公司业务相关的云端文件与表格。

这是什么

Kakaer Drive 是由广州卡卡尔汽车改装设计有限公司（Kakaer Automobile）开发并运营的 内部业务工具。它通过 Google 官方的 Drive API / Sheets API， 以本公司授权账号（jackiechen283231@gmail.com）的身份， 访问与本公司业务相关的 Google 云端硬盘文件和 Google 表格。

该应用为自用型应用：开发者和使用者均为本公司，不向公众提供服务，不开放第三方注册。

用来做什么

  • 读取客户（如海外经销商）与本公司的共享业务表格，用于订单对账与交期跟进
  • 将 Google 表格导出为 Excel / CSV 供内部记账系统核对
  • 上传发货资料、产品图片等业务文件到本公司云端硬盘
  • 更新本公司维护的共享表格数据
Google Drive API Google Sheets API 内部业务工具 仅限授权账号使用

数据如何处理

本应用的访问凭据仅保存在授权用户本人的本地计算机上，不存储在任何服务器上； 通过接口读取的 Google 用户数据仅用于上述业务用途，不向任何第三方共享、出售或转移。 详细说明见隐私政策与服务条款：
