1. 我们是谁

本隐私政策适用于 Kakaer Drive —— 由广州卡卡尔汽车改装设计有限公司 （Kakaer Automobile，以下简称"我们"）开发并运营的内部业务工具。 本应用的开发者与使用者均为本公司，不向公众提供服务。

联系方式：jackiechen283231@gmail.com

2. 我们访问哪些 Google 用户数据

本应用通过 Google 官方 API 以下列授权范围（scope）访问 Google 用户数据：

  • https://www.googleapis.com/auth/drive —— Google Drive 完整读写权限：查看、下载、上传、修改与本公司业务相关的云端文件， 以及导出 Google 表格。

访问范围仅限完成授权的 Google 账号（本公司授权用户 jackiechen283231@gmail.com）有权限查看的文件，包括他人主动与该账号共享的文件。

3. 我们如何使用这些数据

通过 API 访问的数据仅用于本公司自身的业务运营，包括：

  • 读取合作客户共享的订单表格，进行订单登记、对账与交期跟进；
  • 将业务表格导出为 Excel / CSV 供内部记账核对；
  • 上传发货资料、产品图片等文件至本公司云端硬盘；
  • 更新本公司维护的共享表格。

我们不会将 Google 用户数据用于任何其他目的，包括但不限于：广告、 机器学习模型训练、数据分析售卖或任何形式的再分发。

4. 存储与安全

  • OAuth 访问凭据（access token / refresh token）仅保存在授权用户本人的本地计算机上， 文件权限限制为仅该用户可读，不存储在任何联网服务器上；
  • 本应用不在任何服务器上持久存储 Google 用户数据；
  • 所有与 Google API 的通信均通过 HTTPS 加密进行；
  • 如授权用户不再需要访问，可随时按下文第 6 条撤销授权，本地凭据将被删除。

5. 我们不会共享你的数据

我们不向任何第三方出售、出租、共享或转移通过 API 获取的 Google 用户数据， 法律法规另有强制要求的除外。

6. 如何撤销授权

授权用户可随时访问 Google 账号 - 有权访问您账号的第三方应用 页面，找到 Kakaer Drive 并移除访问权限。撤销后本应用将立即无法访问任何 Google 数据。

7. 政策更新

若本应用的数据访问方式发生实质变化，我们将在本页面更新隐私政策并修改生效日期。
